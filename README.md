# SortingTrash2D

เกม 2D สื่อการเรียนรู้เรื่องการแยกขยะสำหรับนำเสนอในงานวันวิชาการ ออกแบบเกมเพลย์ให้เล่นง่าย และใส่ระบบ Leaderboard จัดอันดับคะแนนเพื่อกระตุ้นให้ผู้เล่นแข่งกันทำคะแนนสูงๆ

## คุณสมบัติหลัก
- ระบบ Leaderboard จัดอันดับคะแนนผู้เล่น
- กราฟิกและเอฟเฟกต์ด้วย Custom Shader (ShaderLab / HLSL)

## พัฒนาด้วย
- Unity Engine (C#)
